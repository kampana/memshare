MCP tool reference

Every tool your AI assistant can call — parameters, what a conversation looks like, and what comes back.

10 tools 4 groups
Core — Read & Write
memory_get Look up what is already known about the user and their work ▾
Parameters
query stringFree text matched against content and tags. Multi-word matches any word.
tags string[]Return items carrying any of these tags.
visibility "private" | "shareable"Filter by visibility. Omit for both.
from stringFilter by source tool — claude-code, cursor-vscode, cli.
limit numberMax items (default 20, max 200).
Conversation
You"what do you know about the auth service?"
AIcalls memory_get({ query: "auth service" })
Response
Found 3 memories: 1. Auth service uses JWT with 15-min refresh tokens. tags: auth, backend · visibility: shareable · from: claude-code 2. Auth endpoints require the X-Request-ID header for tracing. tags: auth, observability · visibility: shareable · from: cursor-vscode 3. The old SAML flow was removed in v2.4; don't reference it. tags: auth · visibility: private · from: cli
memory_set Save one durable fact — a decision, a preference, a convention ▾
Parameters
content string requiredThe fact as a standalone sentence.
visibility "private" | "shareable" requiredshareable for project facts; private for personal preferences.
tags string[]Topic tags, e.g. ["auth", "deploy"]. Project tag is added automatically.
Conversation

Response
✓ Saved (id: mem_a3f8c2d1) content: The team chose Postgres over MySQL for its JSONB support. visibility: shareable · tags: database, architecture

memory_set_visibility Mark memories as shareable (eligible for export) or private ▾
Parameters
visibility "private" | "shareable" requiredThe new visibility.
ids string[]Specific memory ids to change.
query stringMatch memories by text content.
tags string[]Match memories by tag.
Conversation

Response

Sharing — Send & Receive
memory_export Write a bundle file to send to someone ⟳ two-phase ▾
Parameters
for stringWho the bundle is for. Recorded in it.
query stringLimit to memories matching this text.
tags string[]Limit by tag.
expires stringRefuse import after this, e.g. "30d".
note stringA note to the recipient.
confirmed booleanOmit to preview. true to write the file.
Conversation (two-phase)
You"send Dana the architecture notes"
AI1st call (preview) — shows exactly what would go in
You"looks good"
AI2nd call with confirmed: true — writes the bundle
Response (preview)
Would export 5 memories for Dana, expiring in 7 days: ✓ API uses cursor-based pagination, not offset. ✓ The team chose Postgres for JSONB support. ✓ Deploy requires manual prod approval. ✓ Error boundaries wrap each route. ✓ Rate limiter is 100 req/min per API key. ⚠ Held back (private): Prefers dark mode in all editors. Say "go ahead" to write the bundle, or adjust.
Response (confirmed)
✓ Bundle written. path: ~/.memshare/bundles/bundle-a3f8c2d1.memshare.json for: Dana · items: 5 · expires: 2026-09-28 Send the file however you like — email, Slack, AirDrop.
